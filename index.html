ขั้นตอนการนำ Dashboard ขึ้น GitHub Pages

1

บันทึกไฟล์ HTML

เซฟไฟล์นี้ลงในคอมพิวเตอร์ของคุณในชื่อ index.html

2

สร้าง Repository บน GitHub

เข้าเว็บ GitHub.com แล้วสร้าง Repository ใหม่ (เช่น health-dashboard) และเลือกเป็น Public

3

อัปโหลดไฟล์ index.html

กดที่ "Add file" → "Upload files" บน GitHub ลากไฟล์ index.html วาง แล้วกด Commit Changes

4

เปิดใช้งาน GitHub Pages

ไปที่ Settings → Pages เลือก Branch เป็น main แล้วกด Save
